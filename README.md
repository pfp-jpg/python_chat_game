# creater:Fku

## 遊び方
- ブラウザ版: GitHub Pages のURL(リポジトリの Settings → Pages に表示されます)を開いて、画面をクリックするとスタートします。
- キー操作: ↑↓←→ で選択 / Z で決定 / X でメニューの開閉 / C で天気の場所を変更(ブラウザ版)
- セーブはブラウザの localStorage に自動で保存されます(同じブラウザなら続きから遊べます)。
- 初回に天気を取得する場所(都市名)を聞かれます。入力した場所はブラウザに保存されます。

## 手元(PC)で動かす場合
`pip install pygame` のあと `python main.py`

## 更新のしかた
main に push すると GitHub Actions が自動でビルドして公開します(pygbag を使用)。
